### Final CS 4641: Machine Learning Project

Reproduces *Auto-Encoding Variational Bayes* and improves upon original results with Attention and Beta-based modifications. Evaluates vanilla VAE, β-VAE, and an Attention VAE on MNIST and Fashion-MNIST across reconstruction quality, negative log-likelihood, and latent space structure.
